Withheld publication of information

Some information required by eForms may remain non-public ("undisclosed") indefinitely or for a defined period. This feature may be used for Result, Contract Modification and Contract Completion notices only.

The reason for keeping the information private shall be specified using a code from the codelist non-publication-justification and optionally a description.

To activate the mechanism, four business terms have to be used:

  • Undisclosed Information Group (BT-195)

  • Non-disclosure Justification Code (BT-197)

  • Non-disclosure Justification Additional Information (BT-196)

  • Disclosure Date (BT-198)

The information is encoded using dedicated elements:

<efac:NoticeInformationNondisclosure>
    <!-- BT-198-notice -->
    <efbc:InformationDisclosureDate>2025-03-31+01:00</efbc:InformationDisclosureDate>
    <efac:NondisclosureJustification>
        <!-- BT-197-notice -->
        <cbc:NondisclosureJustificationCode listName="non-publication-justification">oth-int</cbc:NondisclosureJustificationCode>
        <!-- BT-196-notice -->
        <efbc:NondisclosureJustificationDescription languageID="ENG">Information delayed publication because of ...</efbc:NondisclosureJustificationDescription>
        <efbc:NondisclosureJustificationDescription languageID="FRA">Publication de l'information ajournée parce que ...</efbc:NondisclosureJustificationDescription>
    <efac:NondisclosureReference>
        <!-- BT-195-notice -->
        <efbc:NondisclosureID>cri-awrd</efbc:NondisclosureID>
    <efac:NondisclosureReference>
</efac:NoticeInformationNondisclosure>

The information to be withheld should use the extension mechanism at notice level (element ContractAwardNotice). This single structure replaces the implementation in previous versions of the SDK where unpublished information fields were located at the same level as the fields to be withheld.

The groups of fields to be withheld should be indicated using one or more codes from the codelist undisclosed-data-group in the repeatable field Undisclosed Information Group (BT-195-notice).

Further information about undisclosed fields is available on the TED website.

Markup of withholdable groups

A markup sample is provided below to illustrate the use of the Undisclosed Information Group (BT-195-notice).

<ContractAwardNotice>
    <ext:UBLExtension>
        <ext:ExtensionContent>
            <efext:EformsExtension>
            <!-- Interrupted mark-up -->
            <efac:NoticeInformationNondisclosure>
                    <efbc:InformationDisclosureDate>2030-04-23+01:00</efbc:InformationDisclosureDate>
                <efac:NondisclosureJustification>
                        <efbc:NondisclosureJustificationCode listName="non-publication-justification">eo-int</efbc:NondisclosureJustificationCode>
                        <efbc:NondisclosureJustificationDescription languageID="ENG">Additional information on the non-publication justification</efbc:NondisclosureJustificationDescription>
